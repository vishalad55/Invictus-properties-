# Image slots

Drop supplied, cleared photography here using these exact filenames. Until a
file exists, the page renders a labelled slot in development and a neutral
block in production. Nothing is hotlinked from a stock library.

| Filename | Used on | Notes |
| --- | --- | --- |
| `home-hero.jpg` | Home hero | Full-bleed. A muted 8–10s loop may replace it; supply as `home-hero.mp4` plus a poster frame and tell us to switch it in. |
| `work-allure-avani-hero.jpg` | Work index, Allure Avani case study | Needs client clearance. |
| `work-urban-greens-hero.jpg` | Work index, Urban Greens case study | Needs client clearance. |
| `work-shangrila-hero.jpg` | Shangrila case study | Needs written client approval. Page is behind `NEXT_PUBLIC_SHOW_SHANGRILA`. |

## What we need for each image

- Written permission to publish it, from whoever owns it.
- The largest version available. We resize; we cannot invent detail.
- A one-line description of what it shows, so the alt text is accurate.

Landscape images work best at 3:2 or wider. Card images are cropped to 4:5 on
the home page, so keep the subject away from the edges.
